VS Code の演習を始める前に、Tailspin Toys リポジトリのコピーと GitHub Codespaces の環境を準備します。

1. [Tailspin Toys template][tailspin-template] を開きます。
2. **Use this template** を選択し、リポジトリを作成します。
3. 新しいリポジトリで **Code**、**Codespaces** の順に選択し、codespace を作成します。
4. codespace が VS Code ブラウザー版で開いたら、ターミナルが利用できることを確認します。

> [!NOTE]
> ローカルの VS Code を使用する場合は、リポジトリをクローンし、dev container を開いてください。

次は、[カスタム指示][next-lesson]を設定します。
