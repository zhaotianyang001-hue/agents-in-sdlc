VS Code のエージェントモードを使い、UI、データ層、テストにまたがるフィルター機能を実装します。

1. Copilot Chat を開き、モードを **Agent** に設定します。
2. Copilot にゲーム一覧へのフィルター機能の追加を依頼します。
3. 使用するファイル、データモデル、テストの範囲を確認します。
4. 提案された変更をレビューし、必要に応じてフィードバックします。
5. アプリを起動してフィルターをテストします。

> [!IMPORTANT]
> Copilot が変更したすべてのファイルを確認し、意図しない変更やセキュリティ上の問題がないことを確認してください。
