リポジトリに定義されたアクセシビリティエージェントを確認し、特定のタスクに使用します。

1. `.github/agents/accessibility.md` を開きます。
2. エージェントの責務、ベストプラクティス、コーディング例を確認します。
3. Copilot にハイコントラストモードの実装を依頼し、アクセシビリティエージェントを使用します。
4. 提案された変更をレビューし、コントラスト、キーボード操作、設定の保存を確認します。

次は、[エージェントセッションの管理][next-lesson]を確認します。
