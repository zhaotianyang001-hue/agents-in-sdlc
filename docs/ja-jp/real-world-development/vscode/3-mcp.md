Playwright MCP サーバーを有効にして、Copilot がブラウザーを操作してフィルター機能をテストできるようにします。

1. VS Code の MCP サーバー設定を確認します。
2. Playwright MCP サーバーを有効にします。
3. Copilot にアプリを起動し、フィルターを使ってブラウザーで検証するよう依頼します。
4. 検出された問題を修正し、再度テストします。

次は、[カスタムエージェント][next-lesson]を確認します。
