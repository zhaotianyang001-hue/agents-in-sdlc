エージェントセッションを監視し、必要に応じて作業を方向付けます。

1. エージェントダッシュボードまたは Copilot のセッションビューを開きます。
2. セッションの進捗、計画、変更を確認します。
3. 要件に合わない結果があれば、具体的なフィードバックを追加します。
4. 完了したらプルリクエストをレビューしてマージします。

次は、[Copilot の作業を反復して改善][next-lesson]します。
