エージェントダッシュボードでは、実行中のタスクを確認し、セッションの進行状況を監視し、必要に応じて追加の指示を与えられます。

1. GitHub のエージェントダッシュボードを開きます。
2. ハイコントラストモードのセッションを選択します。
3. エージェントの計画、ツールの使用状況、変更を確認します。
4. 必要な修正や制約がある場合は、セッションに追加の指示を送ります。
5. 実装が完了したら、作成されたプルリクエストをレビューします。

> [!TIP]
> セッションの途中でも方向付けできますが、要件は Issue またはセッションの指示に明確に記載してください。
