クラウドエージェントの演習を始める前に、Tailspin Toys リポジトリのコピーと作業用 codespace を準備します。

## ラボリポジトリをセットアップする

1. [Tailspin Toys template][tailspin-template] を新しいブラウザータブで開きます。
2. **Use this template** を選択し、必要な権限がある組織または個人アカウントにリポジトリを作成します。

   ![Use this template ボタン](../../../_images/ex0-use-template.png)

3. 作成したリポジトリ名とパスをメモします。

## codespace を作成する

1. 作成したリポジトリで緑色の **Code** ボタンを選択します。
2. **Codespaces** タブを開き、**+** を選択します。
3. codespace の作成が完了するまで待ちます。

> [!CAUTION]
> 今後の演習で codespace を使用するため、ブラウザーのタブを開いたままにしてください。
