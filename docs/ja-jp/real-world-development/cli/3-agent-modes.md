Copilot CLI の Plan モードと Autopilot モードを使い、フィルター機能を段階的に実装します。

1. `/plan` または Plan モードを選択して、要件と実装アプローチを確認します。
2. データ取得、UI、テストを含む変更範囲を承認します。
3. Copilot にフィルター機能の実装を依頼し、変更を段階的にレビューします。
4. テストとブラウザーでの動作確認を行います。

次は、[カスタム指示][next-lesson]を確認します。
