再利用可能な QA エージェントを使い、ブラウザーでの動作確認とテストのレビューを依頼します。

1. リポジトリまたはユーザー設定にある QA エージェントを確認します。
2. エージェントに、フィルター機能の主要な操作をテストするよう依頼します。
3. 不具合、アクセシビリティ上の問題、欠けたテストケースを確認します。
4. 修正を実装し、再テストします。

次は、[プルリクエストの作成][next-lesson]を行います。
