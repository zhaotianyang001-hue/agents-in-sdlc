Playwright MCP サーバーを使って、Copilot にブラウザー操作と機能テストを依頼します。

1. Copilot CLI の MCP 設定を確認します。
2. Playwright MCP サーバーを有効にします。
3. アプリを起動し、Copilot にブラウザーでフィルター機能をテストするよう依頼します。
4. テスト結果を確認し、失敗があれば修正を依頼します。

> [!NOTE]
> MCP は外部ツールへの安全な接続を提供しますが、エージェントが実行する操作は毎回レビューしてください。

次は、[QA エージェント][next-lesson]を確認します。
