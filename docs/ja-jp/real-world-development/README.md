現実的なシナリオ、完成済みのアプリケーション、共通のバックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を体験します。計画、コード作成、動作テスト、プルリクエストのレビュー、エージェントによる作業管理を反復的に行います。

## シナリオ

ボードゲーム向けクラウドファンディングを提供する架空の企業 Tailspin Toys に、あなたは新しく開発者として参加します。チームのバックログは GitHub Issue として登録済みで、フィルター、ページネーション、アクセシビリティ、コーディング規約などのタスクから選択できます。

## 環境を選択

GitHub Copilot は作業環境を選ばず利用できます。使用したい環境に合ったワークショップを選択してください。各ワークショップは独自のセットアップから始まり、共通の Tailspin Toys シナリオを使用します。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを操作します。Plan モード、Autopilot モード、命令、スキル、カスタムエージェント、Playwright MCP を体験します。

### [GitHub Copilot app][app]

複数のエージェントセッションを並行実行し、セッションモードを切り替え、キャンバスや GitHub Issue、プルリクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub Issue を非同期エージェントに割り当て、作業を監視し、作成されたプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で Copilot Chat のエージェントモード、MCP サーバー、カスタムエージェントを使用します。
