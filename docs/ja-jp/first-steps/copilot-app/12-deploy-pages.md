この演習では、Space Quiz を GitHub Pages に公開し、リポジトリにアクセスできる人が開けるようにします。

## GitHub Pages を有効にする

1. GitHub のリポジトリで **Settings** を開きます。
2. 左側のメニューから **Pages** を選択します。
3. **Build and deployment** の **Source** で **GitHub Actions** を選択します。
4. ワークフローを実行し、デプロイされたサイトの URL を確認します。

## デプロイを確認する

- 公開された URL をブラウザーで開きます。
- クイズを実行し、主要な画面で動作を確認します。
- デプロイ失敗があれば GitHub Actions のログを確認し、必要な修正を依頼します。
