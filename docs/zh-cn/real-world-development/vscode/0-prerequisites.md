在开始 VS Code 练习之前，需要准备 Tailspin Toys 存储库副本和 codespace。

1. 在浏览器中打开 [Tailspin Toys 模板][tailspin-template]。
2. 选择 **Use this template**，再选择 **Create a new repository**。
3. 按需要选择组织或个人账户，并记下存储库路径。

    ![Use this template 按钮](../../../_images/app-0-use-template.png)

4. 打开新存储库，选择绿色的 **Code** 按钮。
5. 在 **Codespaces** 选项卡中创建新的 codespace。

> [!NOTE]
> 本工作坊可在 codespace 或本地开发容器中运行。两者都应提供已预装的 Node.js、依赖和测试工具。

## 总结

你已准备好用于练习的存储库和 VS Code 环境。下一课将添加和验证自定义指令。
