进行更复杂的代理任务时，应监控会话、审阅工具调用，并在必要时引导代理。

1. 查看 Copilot Chat 中的活动会话。
2. 检查代理读取或修改的文件。
3. 若方向偏离需求，发送简洁的新指令重新限定范围。
4. 使用差异视图审阅最终更改。
5. 在合并前运行项目测试。

> [!NOTE]
> 引导代理时应说明具体目标、约束和期望的验收标准。
