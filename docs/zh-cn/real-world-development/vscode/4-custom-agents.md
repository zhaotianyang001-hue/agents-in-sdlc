自定义代理可把团队专业知识固化为可复用的开发角色。

1. 打开 `.github/agents` 文件夹。
2. 审阅代理的 YAML frontmatter 和 Markdown 提示。
3. 在 Copilot Chat 中选择合适的自定义代理。
4. 分配一个与该代理职责一致的任务。
5. 审阅代理修改的文件及测试结果。

> [!CAUTION]
> 自定义代理的 `name` 和 `description` 是必需的 frontmatter 字段。
