VS Code 的 Copilot Chat 可在代理模式中探索存储库、编辑文件并运行工具。

1. 打开 Copilot Chat，并从模式选择器中选择 **Agent**。
2. 选择合适的模型。
3. 请求代理实现筛选功能或修复指定 Issue。
4. 审阅代理提出的计划和工具操作。
5. 使用编辑器差异视图检查每项修改。
6. 运行测试并让代理修复失败项。

> [!NOTE]
> 在合并前应始终审阅代理生成的代码和测试。
