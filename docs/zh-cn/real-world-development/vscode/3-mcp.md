MCP 可让 Copilot 在代理模式中连接外部工具和服务。

1. 在 VS Code 中检查 MCP 服务器配置。
2. 启动所需服务器并确认其状态。
3. 在 Copilot Chat 中请求代理使用 MCP 工具完成任务。
4. 审阅工具调用及其产生的数据。
5. 对代理的结果进行人工验证。

> [!IMPORTANT]
> MCP 可访问外部资源，应只批准已审阅的工具操作。
