通过真实场景、完整应用和共享待办事项，探索软件开发生命周期中的 GitHub Copilot。你将迭代地规划变更、编写代码、测试行为、审阅拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的一名新开发人员。这是一家虚构公司，面向开发者主题的桌游提供众筹服务。团队的待办事项已作为 GitHub Issues 建档，随时可以领取。其中既包括筛选和分页等功能需求，也包括无障碍和编码规范等质量改进。

## 选择环境

无论你在哪个环境中工作，GitHub Copilot 都能为你提供支持。请选择与你的构建方式相符的环境。每个工作坊都有独立的设置，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。使用规划和自动驾驶模式、指令、技能、自定义代理、Playwright MCP、代理合并以及实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行代理会话，切换会话模式，在画布上协作，并管理 GitHub Issues 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub Issues 分配给异步代理，指导其工作，监控进度，并审阅其创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
