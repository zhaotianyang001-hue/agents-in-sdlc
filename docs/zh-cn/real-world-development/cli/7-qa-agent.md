可使用自定义代理将质量检查固化为可复用角色。QA 代理应检查功能、测试、无障碍性和回归风险。

1. 查看 `.github/agents` 中的 QA 代理定义。
2. 确认代理的名称、说明和职责清晰。
3. 在拉取请求或分支上运行 QA 代理。
4. 审阅发现的问题，并让代理修复可安全处理的内容。
5. 对建议的每项更改再次运行测试。

> [!NOTE]
> 自定义代理可补充人工审阅，但不能替代人工审阅。
