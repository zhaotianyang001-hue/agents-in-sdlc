模型上下文协议（MCP）可让 Copilot 连接外部工具。在本课中，你将使用 Playwright MCP 在浏览器中测试应用。

1. 确认仓库中的 Playwright MCP 配置。
2. 启动 Copilot CLI。
3. 请求代理打开应用并检查筛选功能、星级评分或其他页面行为。
4. 要求代理使用浏览器快照定位问题。
5. 审阅代理发现的异常并让它修复。

> [!IMPORTANT]
> MCP 工具可访问外部或本地资源；只批准已审阅的操作。
