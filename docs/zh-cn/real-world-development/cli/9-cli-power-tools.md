Copilot CLI 提供多种斜杠命令和会话功能：

- `/new`：开始新会话；
- `/diff`：审阅当前更改；
- `/context`：查看上下文用量；
- `/compact`：压缩上下文；
- `/delegate`：委派给云代理；
- `/worktree`：为独立任务创建工作树；
- `/exit`：退出 CLI。

使用这些命令时，请先确认当前分支、工作树和未提交更改。

> [!CAUTION]
> 委派前应审阅任务范围、分支和目标存储库。
