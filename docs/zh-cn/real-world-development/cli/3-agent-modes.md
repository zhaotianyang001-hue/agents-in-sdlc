## 场景

Tailspin Toys 的游戏列表需要筛选功能，以便用户按类别查找游戏。在本课中，你将使用代理模式规划并实现筛选功能。

## 使用计划模式

1. 从当前分支创建功能分支。
2. 在 Copilot CLI 中进入 `/plan` 模式或选择规划模式。
3. 请求代理分析筛选需求并提出实现计划。
4. 审阅计划，并让代理只在获得必要批准后执行变更。

## 实现筛选功能

使用清晰的提示词说明：

- 筛选控件应位于游戏列表页；
- 支持按类别筛选；
- 保持现有布局；
- 添加测试并运行相关检查。

## 使用自动驾驶模式

在计划获得批准后，可以切换到自动驾驶模式，让 Copilot 持续执行实现、测试和修复步骤。定期审阅 `/diff`，不要在 PR 前跳过代码审阅。

> [!NOTE]
> 自动驾驶会执行多步操作，应始终审阅其生成的代码和外部副作用。
