完成实现和测试后，使用 Copilot CLI 创建并审阅拉取请求。

1. 使用 `/diff` 检查全部更改。
2. 确认测试和检查通过。
3. 输入 `/pr create`。
4. 审阅 PR 标题、正文和变更文件。
5. 合并前确认没有意外更改、密钥或破坏性变更。

> [!TIP]
> PR 描述应说明改动原因、验证方式和潜在风险。
