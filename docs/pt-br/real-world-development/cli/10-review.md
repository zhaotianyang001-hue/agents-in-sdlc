Nesta etapa final, revise tudo o que você criou com o GitHub Copilot CLI e escolha os próximos passos.

## Revisar o trabalho

1. Confira a lista de alterações e a qualidade dos testes.
2. Revise a pull request e os comentários dos revisores.
3. Confirme que os workflows necessários foram aprovados.
4. Faça o merge somente quando o trabalho estiver concluído e verificado.

## Próximos passos

Considere aplicar os mesmos fluxos em issues reais do backlog ou explorar os workshops do VS Code e do cloud agent.
