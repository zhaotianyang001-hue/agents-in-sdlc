Os arquivos de instruções fornecem contexto persistente ao Copilot. Neste exercício, você adicionará padrões específicos ao repositório.

## Adicionar instruções

1. Abra `.github/copilot-instructions.md`.
2. Adicione os padrões de documentação e cabeçalhos de arquivo necessários.
3. Use arquivos `.github/instructions/*.instructions.md` para regras específicas de linguagens ou tipos de arquivos.
4. Peça ao Copilot que revise uma alteração e confirme que ele segue as novas instruções.
