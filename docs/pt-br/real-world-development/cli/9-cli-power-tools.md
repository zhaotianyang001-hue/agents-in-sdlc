Neste exercício, você combina recursos do Copilot CLI para resolver uma tarefa mais complexa.

## Combinar recursos

- use instruções personalizadas para contexto persistente;
- use skills para processos especializados;
- use o modo Plan para revisar antes de alterar;
- use MCP para interagir com ferramentas externas.

## Concluir a tarefa

Defina o resultado esperado, divida o trabalho em etapas verificáveis e revise cada alteração antes de prosseguir.
