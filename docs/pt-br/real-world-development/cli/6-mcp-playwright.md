Neste exercício, você usa o servidor MCP do Playwright com o Copilot CLI para testar a aplicação em um navegador.

## Conectar o servidor MCP

1. Configure o servidor MCP do Playwright no ambiente do CLI.
2. Confirme que o Copilot consegue listar e usar as ferramentas do servidor.
3. Inicie a aplicação localmente.

## Executar testes no navegador

Solicite ao Copilot que navegue pela aplicação, aplique filtros e confirme que os resultados esperados sejam exibidos. Peça que ele reporte também erros no console e falhas de acessibilidade.
