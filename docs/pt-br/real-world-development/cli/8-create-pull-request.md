Depois de implementar e testar a funcionalidade, crie uma pull request revisada.

## Preparar as alterações

1. Examine o estado da branch e confirme que apenas os arquivos esperados foram alterados.
2. Execute os testes relevantes.
3. Solicite ao Copilot que resuma as alterações e redija a descrição da pull request.
4. Verifique a descrição e os links antes de enviar.

## Criar a pull request

Use o GitHub CLI ou a interface do GitHub para abrir a pull request e aguarde os checks obrigatórios.
