Neste exercício, você usará o GitHub Copilot CLI para adicionar uma avaliação por estrelas à página de detalhes do jogo.

## Cenário

A equipe deseja permitir que os visitantes atribuam uma nota a um jogo e vejam a nota atual.

## Implementar o recurso

1. Abra o terminal no repositório Tailspin Toys.
2. Inicie o Copilot CLI.
3. Solicite que o agente adicione o componente de avaliação por estrelas à interface.
4. Peça que ele atualize o modelo de dados e crie testes.
5. Revise o diff e execute os testes.

> [!TIP]
> Forneça requisitos claros e peça ao agente que explique as alterações antes de aplicá-las.
