Neste exercício, você usa um agente de QA personalizado para verificar a implementação.

## Revisar o agente

Abra `.github/agents/qa.md` e examine os critérios usados pelo agente para revisar funcionalidade, testes e acessibilidade.

## Executar a revisão

Solicite ao agente de QA que:

- valide os casos de uso principais;
- execute os testes disponíveis;
- verifique mensagens de erro e estados vazios;
- informe defeitos específicos com base nas evidências.

Não considere uma revisão aprovada até que os problemas sejam corrigidos ou explicitamente justificados.
