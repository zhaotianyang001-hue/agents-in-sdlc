Neste exercício, você compara os modos de agente disponíveis no Copilot CLI e escolhe o modo adequado para cada tarefa.

## Modos disponíveis

- use o modo interativo para discutir requisitos e revisar resultados;
- use o modo Plan para investigar e apresentar um plano antes das alterações;
- use o modo Autopilot para permitir que o agente execute uma tarefa bem definida.

## Experimentar um modo

Peça ao agente que descreva o plano para implementar uma pequena melhoria. Revise o plano, solicite ajustes e somente então permita a execução.
