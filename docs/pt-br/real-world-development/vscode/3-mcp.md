Neste exercício, você conecta o servidor MCP do Playwright ao Copilot para testar a aplicação em um navegador real.

## Configurar o Playwright MCP

1. Abra o Copilot Chat no VS Code.
2. Configure o servidor MCP do Playwright conforme as instruções do projeto.
3. Reinicie o servidor MCP, se necessário.
4. Confirme que o Copilot consegue acessar as ferramentas do Playwright.

## Testar no navegador

Peça ao Copilot que abra a aplicação, selecione categorias e termine uma busca. Solicite que ele confirme os resultados visíveis e capture erros do console.

> [!TIP]
> Testar no navegador complementa os testes automatizados e ajuda a encontrar problemas de layout, interação e acessibilidade.
