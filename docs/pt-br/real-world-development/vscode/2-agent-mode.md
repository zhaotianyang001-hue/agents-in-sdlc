O modo agent permite que o Copilot trabalhe em várias etapas, explore o projeto e faça alterações em vários arquivos. Neste exercício, você o usará para adicionar filtragem à lista de jogos.

## Cenário

A Tailspin Toys precisa permitir que as pessoas encontrem jogos por categoria e termo de busca. A implementação deve incluir interface, acesso aos dados e testes.

## Usar o modo agent

1. Abra o Copilot Chat e selecione o modo **Agent**.
2. Informe ao Copilot que implemente filtros na lista de jogos.
3. Peça que localize o padrão atual de dados, adicione testes e execute os checks.
4. Revise cada alteração antes de aceitá-la.

> [!NOTE]
> Um prompt bem definido deve indicar o comportamento esperado, os arquivos ou áreas relevantes e os testes necessários.
