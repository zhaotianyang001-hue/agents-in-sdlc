Explore o GitHub Copilot em todo o ciclo de desenvolvimento de software usando cenários realistas, uma aplicação completa e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar comportamentos, revisar pull requests e gerenciar tarefas com agentes.

## Cenário

Você é uma pessoa desenvolvedora nova na Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com temática de desenvolvedores. O backlog da sua equipe já está registrado como issues do GitHub e pronto para você assumir. Ele inclui trabalhos de recursos, como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de codificação.

## Escolha seu ambiente

O GitHub Copilot está disponível onde quer que você trabalhe. Escolha o ambiente que corresponde à forma como deseja criar. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente agentic no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra práticos.

### [GitHub Copilot app][app]

Execute sessões de agentes em paralelo, alterne entre modos de sessão, colabore em canvases e gerencie issues e pull requests no aplicativo para desktop.

### [GitHub Copilot cloud agent][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente seu trabalho, monitore o progresso e revise as pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo agent do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
