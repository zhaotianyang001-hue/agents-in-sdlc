Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya contiene incidencias preparadas para que puedas trabajar en ellas. Incluye funcionalidades como el filtrado y la paginación, junto con mejoras de calidad como la accesibilidad y las normas de codificación.

## Elige tu entorno

GitHub Copilot te acompaña donde trabajes. Elige el entorno que se ajuste a cómo quieres desarrollar. Cada taller comienza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Utiliza el asistente agéntico en tu terminal. Trabaja con los modos Plan y Pilotaje automático, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y comandos prácticos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios en la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asincrónico, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que crea.

### [Visual Studio Code][vscode]

Utiliza GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
